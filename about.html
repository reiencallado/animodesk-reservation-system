About AnimoDesk

Built for secure student lab reservations.

AnimoDesk is a lightweight, campus-ready reservation system with account protection, profile management, and role-based workflows for students and lab technicians.

Login Register

Core features

  • Student and technician accounts with secure session authentication.
  • Password hashing using bcrypt and validation on both frontend and backend.
  • Database-driven lab listings, reservations, and user profiles.
  • Responsive UI with consistent styling and a dark/light theme toggle.

Technology stack

  • Node.js + Express
  • MongoDB via Mongoose
  • express-session for auth
  • bcrypt for hashing

Security notes

  • Passwords are never stored in plaintext.
  • Forms are validated before submission.
  • Session cookies remain active until closed.
