About AnimoDesk

AnimoDesk is a lab reservation and profile management application built with secure user authentication and form validation.

Authentication persists for the browser session until the user either logs out or closes the browser window.

NPM packages used

  • express — web server framework
  • express-session — session management for authentication
  • mongoose — MongoDB object modeling
  • bcrypt — password hashing

Third-party libraries used

  • Font Awesome — icon library loaded from CDN

Security notes

  • User passwords are hashed before they are stored in the database.
  • All authentication-related forms are validated on both the front end and back end.
  • Session cookies are configured to remain active until the browser window is closed.
